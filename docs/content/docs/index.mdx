---
title: "SkyDiscover"
description: "An open-source framework from UC Berkeley that uses AI to discover better algorithms and build complete systems."
---

SkyDiscover has two parts:

- **Optimize**: improve an algorithm or a component of your system. You provide a way to score
  solutions, and evolutionary search finds programs that score better and better.
- **Synthesize**: build an end-to-end system. You describe it in plain text or a formal spec, and
  coding agents build it for your workload, hardware, and requirements.
