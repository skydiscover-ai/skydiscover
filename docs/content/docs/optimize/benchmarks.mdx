The [`benchmarks/`](https://github.com/skydiscover-ai/skydiscover/tree/main/benchmarks)
directory ships hundreds of tasks across ten suites, each with an evaluator and usually a seed program and config, so
results are reproducible and comparisons between algorithms are fair.

## Dependency extras

Benchmarks with heavier dependencies are behind optional extras:

```bash
uv sync                              # Base install
uv sync --extra math                 # Math benchmarks (SciPy, JAX, PyWavelets, …)
uv sync --extra adrs                 # ADRS systems benchmarks
uv sync --extra frontier-cs          # Frontier-CS benchmark tooling
uv sync --extra external             # OpenEvolve / GEPA backends (ShinkaEvolve is a manual install)
uv sync --extra prompt-optimization  # HotPotQA prompt optimization
```

Combine extras as needed: `uv sync --extra external --extra math`. If a benchmark ships
its own `requirements.txt`, also run `uv pip install -r path/to/requirements.txt`.

## Running a benchmark

Every benchmark is run through the same CLI:

```bash
uv sync --extra math
uv run skydiscover optimize benchmarks/math/circle_packing/initial_program.py \
  benchmarks/math/circle_packing/evaluator.py \
  --config benchmarks/math/circle_packing/config.yaml \
  --search adaevolve \
  --iterations 100
```

## Harbor benchmark suites

SkyDiscover natively supports [Harbor](https://harborframework.com/)-format tasks, so
external suites run out of the box: AlgoTune, EvoEval, HumanEvalFix, BigCodeBench,
LiveCodeBench, USACO, CRUSTBench, CodePDE, and more:

```bash
uv tool install --python 3.12 harbor   # the Harbor CLI needs Python >= 3.12
harbor datasets download algotune@1.0 -o /tmp/algotune
uv run skydiscover optimize /tmp/algotune/<id>/algotune-set-cover \
  --model anthropic/claude-sonnet-4-6 \
  --search best_of_n -i 10
```
